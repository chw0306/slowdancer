# SlowDancer — 느리게 연습

**Hear it slower. Learn it right.**

음정을 유지한 채 25~200%로 속도를 바꿔주는, 악기·어학 연습 전용 플레이어입니다.
A pitch-preserving practice player for musicians and language learners.

👉 **[Google Play에서 받기 / Get it on Google Play](https://play.google.com/store/apps/details?id=com.slowdancer.app)**
👉 **[소개 페이지 / Landing page](https://chw0306.github.io/slowdancer/)**

---

## 주요 기능 / Features

| | |
|---|---|
| 🎚 **음정 유지 배속** | 25~200%, 느려도 음정 그대로 · Pitch-preserved speed |
| 🎼 **피치 조절** | 반음 단위 ±12 · ±12 semitones |
| 🔁 **A-B 구간반복** | 0.5초 미세조정 · 구간 저장 · Loop with 0.5s nudge & presets |
| 🎛 **7밴드 EQ** | 좌우 채널 분리 · 7-band EQ with channel isolation |
| ♩ **프로 메트로놈** | 액센트 편집 · 카운트인 · 스피드/리듬 트레이너 |
| 🎤 **마이크 녹음** | 반주 + 목소리 2트랙 · 싱크 자동 보정 |
| 🤖 **AI 자막 · 번역** | 기기 안에서 처리 · On-device Whisper |
| 🌍 **다국어 인식** | 영어 · 프랑스어 · 일본어 · 스페인어 · 독일어 · 중국어 |
| 📊 **스펙트럼 11종** | 실시간 비주얼라이저 · 전체화면 지원 |

## 프라이버시 / Privacy

음악·영상 파일과 녹음물은 기기 밖으로 나가지 않습니다.
자막 번역을 사용할 때만 자막 **텍스트**가 번역 API로 전송됩니다.
자세한 내용은 [개인정보처리방침](https://chw0306.github.io/slowdancer/privacy.html)을 확인해 주세요.

Your media files and recordings never leave your device. Only subtitle **text** is sent to a
translation API, and only when you use the translation feature.
See the [Privacy Policy](https://chw0306.github.io/slowdancer/privacy.html).
